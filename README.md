# Ibrahim Riaz Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project showcases:
- Hero section and personal branding
- About section
- Services offered
- Featured project cards
- Experience timeline
- Skills section
- Testimonials
- Contact form with front-end validation
- Responsive design for desktop and mobile

## Project Structure

```text
Project CG/
├── assets/
│   └── images/
├── porfolio.html
├── portfolio.css
├── index.js
├── README.md
└── other project files
```

## Run Locally

1. Open the project folder.
2. Open `porfolio.html` in your browser.
3. Or serve it locally using a simple static server if preferred.

Example:

```bash
cd "C:\Users\Dell\ibr html\Project CG"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/porfolio.html
```

## Technologies Used

## Customization

You can update the following easily:
- Name and title in `porfolio.html`
- Contact details in the contact section
- Project cards and descriptions
- Styling in `portfolio.css`
- JavaScript behavior in `index.js`
